01The app

Linuxify (the Android application com.linuxify.app) is free software: its source is licensed under the GNU General Public License v3.0-or-later (SPDX: GPL-3.0-or-later). You may use, study, modify, and redistribute it under the terms of that license. The authoritative source tree lives at github.com/superz1402/linuxify, where every release tag, build script, and patch is public.

The original Linuxify TypeScript CLI — the engineering reference for the registry, doctor, and compatibility concepts — lives separately at github.com/Bilal140202/linuxify.

02Bundled components

The APK ships with the following third-party components, pinned by SHA-256 and built for bionic. Attribution and verification details are maintained in the repository's docs/RUNTIME.md and docs/THIRD_PARTY_TERMUX_LICENSE.md.

ComponentVersionLicenseUpstream
Termux terminal-emulator / terminal-viewtermux-app v0.118.0 stackGPL-3.0github.com/termux/termux-app

These components are vendored, not downloaded at runtime — the app's supply chain is pinned to the APK itself. The Termux terminal stack's license text ships with the source repository, and nothing in this project claims endorsement by the Termux project.

03Ubuntu base system

The Linux userspace is ubuntu-base 24.04.5 (arm64), downloaded from Canonical's official CD-image servers with checksum verification. Ubuntu base is built from the Ubuntu archive; every package inside it is distributed under its own free-software license (predominantly GPL-compatible). Package sources are available from Launchpad and packages.ubuntu.com.

Ubuntu and Canonical are trademarks of Canonical Ltd. Linuxify is not affiliated with or endorsed by Canonical.

06Corresponding source

For every binary release, the corresponding source is the matching git tag in the public repository:

  • App source: github.com/superz1402/linuxify (releases mirror each tag)
  • Termux terminal stack source: github.com/termux/termux-app
  • proot source: github.com/proot-me/proot + Termux packaging github.com/termux/termux-packages
  • This website: github.com/Bilal140202/linuxify-app

If you need a written offer for source (as some GPL redistribution contexts require), the public repository URL above satisfies it — everything is there, forever.
