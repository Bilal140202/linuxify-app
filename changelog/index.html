~/linuxify/changelog

Every alpha,
on the record.

Fifteen releases in nine days. Production releases ship from the main repository's release cycle — APKs are mirrored here for convenience. Every entry links to its official release with checksums.

current v0.1.0-alpha.15 cycle started October 17, 2026
v0.1.0-alpha.15 latest
October 19, 2026
Persistence, Backup & Restore, Cache Management
  • Terminal sessions persist as full transcripts (scrollback + screen) with metadata; previous runs return as read-only history tabs.
  • One-tap .tar.gz backup via the system file picker; scoped restore (projects / history / environment) with keep-vs-overwrite.
  • Per-project and whole-system cache cleanup with exact-bytes reporting.
  • 144/144 unit tests · APK SHA-256 published on the release.
  • Official release ↗
v0.1.0-alpha.14
October 19, 2026
alpha.13 audit & hardening
  • APT search fixed; eight issues from the alpha.13 audit closed.
  • Hardening across the Universal Software Management System paths.
  • Official release ↗
v0.1.0-alpha.13
October 19, 2026
Universal Software Management System
  • Searchable Software catalog: System / Dev / AI / Network / Media / Data / Text.
  • Installs via APT, npm, pip and checksum-pinned static binaries — with automatic prerequisites and per-tool run verification.
  • Custom user tools flow through the same core; one-tap update & upgrade.
  • Official release ↗
v0.1.0-alpha.12
October 18, 2026
Dependency & Package Recovery Manager
  • Environment audit: Ubuntu version, architecture, storage, network, package-manager health.
  • Repairs the package manager only when it is actually inconsistent — never blindly on launch.
  • BASE environment (curl + HTTPS trust) by default; optional developer profile (git, Node.js, npm).
  • Official release ↗
