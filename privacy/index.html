~/linuxify/privacy

Privacy,
in plain words.

Linuxify collects nothing, sends nothing, and accounts for nothing. This page explains exactly what that means — and the few moments the app touches the network, all of which you trigger yourself.

version 1.0 updated October 20, 2026 applies to com.linuxify.app · all releases

01Summary

Linuxify is a fully local application. It has no servers of its own, no accounts, no analytics SDKs, no advertising SDKs, and no telemetry of any kind. There is literally nothing built into the app that could transmit your data to the developer, because there is no developer-side infrastructure to receive it.

The app uses the network only when you ask it to: downloading the Ubuntu base system, installing or updating packages you selected, cloning a git repository you specified, or serving content to your local network when you explicitly choose to. Your projects, files, terminal history and settings live in app-private storage on your device and never leave it.

02What we collect

Nothing. Specifically:

  • No personal data, no identifiers, no device fingerprints.
  • No usage analytics, no session tracking, no event logging to any remote endpoint.
  • No advertising, no ad identifiers, no cross-app tracking.
  • No accounts, sign-ups, or third-party logins.
  • No cookies or similar technologies inside the app.

Because nothing is collected, there is nothing to sell, nothing to share, and nothing to leak from a developer-side breach.

03What stays on your device

All of it. Everything Linuxify works with lives in Android's app-private storage — a location no other app can read on an unrooted device:

  • The installed Ubuntu environment and its packages.
  • Your projects, including anything you build inside them.
  • Terminal session transcripts and their metadata (start directory, timestamps).
  • Service definitions, app settings, and diagnostic data.

This data persists across restarts and app updates. It is removed when you uninstall the app, use Android's "Clear data" for the app, or run the explicit in-app reset. You can also export a backup archive (.tar.gz) through the system file picker at any time — that archive goes wherever you put it, and the app keeps no copy.

04Network activity

The app only connects to the network when you trigger an action that needs it. These are the only remote destinations the app can contact, and only in those situations:

Action you takeWhere it connects
Install UbuntuUbuntu's official CD-image servers (cdimage.ubuntu.com)
Install / update packagesUbuntu package mirrors; npm registry; PyPI; the pinned static-binary hosts for catalog tools
Clone or push a projectThe git remote you provided
Serve a project to LANYour own local network — off unless you switch it on

Package managers inside the guest environment (apt, npm, pip) behave as they would on any Linux machine: they contact their own ecosystems' infrastructure and send only the standard technical requests those systems require. No data is returned to the developer because there is no developer endpoint.

05Android permissions

Linuxify requests the minimum Android permissions its features need:

  • Notifications — completion alerts for commands and sessions that finish in the background, plus the silent persistent notification required by the foreground service. You can deny this without losing core functionality.
  • Partial wake lock — keeps running sessions and servers alive while the screen is off. In-process capability; not user-facing.
  • Storage access via the system file picker (SAF) — used only when you export a backup archive or restore one, and only for the exact file or folder you pick.

Linuxify never requests access to your contacts, location, microphone, camera, SMS, call logs, or full storage.

06Crash reports

When the app crashes, it saves the error trace locally and shows it to you with a copy button the next time you open the app. Nothing is uploaded — there is no endpoint to upload it to. If you want help with a crash, you copy the trace yourself and paste it into an issue on the public repository. You are the courier; you decide what travels and when.

07This website

This site is fully static and hosted on GitHub Pages. It sets no cookies, loads no analytics, and embeds no tracking pixels. It loads two font CDNs (Fontshare and Google Fonts) and two JavaScript CDNs for scroll animations; your browser's standard requests to those CDNs are governed by those providers' own policies. GitHub, as the host, may log standard server request data under its own privacy terms — see GitHub's privacy statement for details.

08Children

Linuxify is a developer tool and is not directed at children under 13. It collects no data from anyone of any age, so there is nothing age-gated to protect — but if you are a parent and have questions, contact us through the channels below.

09Changes to this policy

If the app ever gains a feature that changes this picture — and the philosophy says it shouldn't — this page will be updated first, with a new version number and date, before the feature ships. Historical versions of this page are available in the site's public repository, so you can always see what changed and when.
